# Requisitos — Luz Cidadã

## 1. Requisitos Funcionais

### RF01 — Cadastro e acesso
O sistema deverá permitir o cadastro e acesso dos usuários de acordo com seus perfis: morador, técnico e gestor.

### RF02 — Registro de ocorrência
O morador deverá poder registrar ocorrências relacionadas à iluminação pública, informando os dados necessários sobre o problema.

### RF03 — Consulta e acompanhamento
O morador deverá poder consultar e acompanhar o andamento das ocorrências registradas.

### RF04 — Triagem e distribuição
O gestor deverá realizar a triagem das ocorrências e distribuí-las aos técnicos responsáveis.

### RF05 — Atualização e conclusão
O técnico deverá poder atualizar o status das ocorrências e registrar sua conclusão.

### RF06 — Mapa
O sistema deverá disponibilizar um mapa para visualização das ocorrências de iluminação pública.

### RF07 — Dashboard e relatórios
O gestor deverá ter acesso a um dashboard com gráficos e relatórios sobre as ocorrências, considerando região, tipo de problema, prioridade e período.

### RF08 — Histórico e rastreabilidade
O sistema deverá manter o histórico das ocorrências, permitindo acompanhar suas alterações e responsáveis.

## 2. Requisitos Não Funcionais

### RNF01 — Usabilidade e responsividade
O sistema deverá apresentar uma interface simples, intuitiva e adaptável a diferentes dispositivos.

### RNF02 — Segurança e privacidade
O sistema deverá proteger os dados dos usuários e controlar o acesso de acordo com cada perfil.

### RNF03 — Desempenho
O sistema deverá apresentar um tempo de resposta adequado durante a utilização.

### RNF04 — Confiabilidade e integridade
Os dados registrados deverão ser armazenados de forma confiável, evitando perdas ou alterações indevidas.

### RNF05 — Manutenibilidade
O sistema deverá possuir uma estrutura organizada, facilitando futuras correções e alterações.

### RNF06 — Acessibilidade
A interface deverá considerar recursos que facilitem a utilização por diferentes usuários.
